# list2026

Списки правил для Clash / mihomo.

## Как устроено

Файлы разделены по типу — так mihomo ищет быстрее, чем в классическом формате:

| Файл | `behavior` | Что внутри |
|---|---|---|
| `*-domain.yaml` | `domain` | домены, формат `'+.example.com'` (сам домен и все поддомены) |
| `*-ip.yaml` | `ipcidr` | подсети, формат `'1.2.3.0/24'` |

В `rule-providers` конфига обязательно указывать `behavior` того же типа, иначе список не загрузится.

## Как добавить домен

Открой нужный файл, добавь строку в конец `payload`:

```yaml
  - '+.новыйдомен.com'
```

Роутер подтянет изменение в течение суток (`interval: 86400`) или сразу после перезапуска Clash.
